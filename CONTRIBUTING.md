# Contributing

Thank you for your interest in AdaptiveStreamFL.

For the initial public release, please keep contributions focused on:

- reproducibility fixes,
- documentation improvements,
- dataset preparation scripts,
- bug fixes that do not change reported experimental behavior unexpectedly.

When submitting changes, include:

- the command used to reproduce or test the change,
- the dataset or synthetic fixture used,
- whether the change affects reported accuracy or runtime.

Do not commit large datasets, generated result folders, local machine logs, or
temporary experiment outputs.
