# Third-Party Notices

## FedStream

AdaptiveStreamFL is related to and compares with the FedStream research line:

- Paper: Mawuli et al., "FedStream: Prototype-Based Federated Learning on Distributed Concept-Drifting Data Streams," IEEE Transactions on Systems, Man, and Cybernetics: Systems, 53(11):7112-7124, 2023, DOI: 10.1109/TSMC.2023.3293462.
- Repository: https://github.com/mvisionai/FedStream

This repository now contains an independent reference implementation of the
AdaptiveStreamFL paper code. It does not include FedStream source files. The
`FedStream` run mode is retained as a compatible baseline-style command-line
mode for experiments and citation context.

Please cite the FedStream paper when discussing that baseline or the relationship
between AdaptiveStreamFL and FedStream.
